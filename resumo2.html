1. Introdução e o Princípio do CSS

O CSS (Cascading Style Sheets) é uma das três linguagens mais importantes para o desenvolvimento frontend. Ele atua como uma linguagem de estilo criada especificamente para controlar a apresentação visual e a exibição de elementos escritos em HTML. Como o HTML padrão exibe uma estrutura visualmente simplificada e dull (sem graça), o CSS surge para tornar os sites atraentes, amigáveis e apelativos ao usuário.

O funcionamento da linguagem é baseado em regras estruturadas em duas partes fundamentais:

  • Seletor: Mecanismo que identifica qual elemento ou grupo de elementos do HTML será alvo da regra de estilo.
  • Declaração: Inserida obrigatoriamente entre chaves {}, ela define as propriedades estéticas do elemento. Cada declaração é formada por uma propriedade (o aspecto a ser mudado) e um valor (a nova diretiva configurada), separados por dois pontos (:) e finalizados por ponto e vírgula (;).

2. Métodos de Incluindo CSS no HTML

O material descreve três maneiras principais de implementar e aplicar as folhas de estilo em um documento HTML:

  • External Stylesheets (CSS Externo): As regras de estilo são gravadas em um arquivo independente com a extensão .css. Esse arquivo é vinculado ao HTML no cabeçalho por meio da tag <link>. É o método mais eficiente pois isola a estrutura do design, simplifica modificações globais e permite que o mesmo arquivo de estilo seja reutilizado por múltiplos documentos web.
  • Internal Stylesheets (CSS Interno): As diretivas de estilo são declaradas diretamente no cabeçalho do documento HTML, inseridas no espaço interno do elemento <style>. Limita a reusabilidade do código para outras páginas do site.
  • Inline Styles (CSS Inline): Os estilos são aplicados diretamente no elemento HTML-alvo utilizando o atributo style na tag de abertura. O código de apresentação mistura-se com a marcação estrutural, anulando completamente o reaproveitamento de código.

Nota do Capítulo: Existe uma quarta opção chamada regra @import. Ela é usada dentro de arquivos CSS ou blocos internos para carregar arquivos CSS adicionais, viabilizando um kit de construção modular.

3. Tipos de Seletores

Os seletores oferecem flexibilidade e controle preciso sobre o documento. Os tipos descritos no texto são:

  • Type Selector (Seletor de Tipo): Seleciona elementos diretamente pelo nome de sua tag HTML (como h1, p ou input).
  • Class Selector (Seletor de Classe): Mapeia elementos que utilizam o atributo global class. No código CSS, é indicado por um ponto final que precede o nome da classe (ex: .valid).
  • ID Selector (Seletor de ID): Direciona a regra para o único elemento que possui o identificador correspondente. No CSS, usa-se o caractere hash ou cerquilha (#) antes do termo (ex: #start). IDs devem ser exclusivos no documento.
  • Universal Selector (Seletor Universal): Indicado pelo caractere asterisco (*), seleciona e aplica as propriedades a todos os elementos existentes na página simultaneamente.
  • Attribute Selector (Seletor de Atributo): Localiza elementos com base em seus atributos e valores entre colchetes, como [type="text"]. Há variações para buscas parciais: começa com (^=), termina com ($=) e contém (*=).
  • Seletores Hierárquicos e de Relacionamento: Filtram os elementos analisando a árvore do HTML. Incluem o seletor de irmão adjacente (+), irmão geral (~), filho direto (>) e descendente geral (indicado por um espaço em branco entre as tags).

4. Cascating, Especificidade e Herança

Quando múltiplas regras entram em conflito ao mirar no mesmo elemento HTML, o navegador resolve o impasse por meio de regras de prioridade:

  • Se os seletores aplicados forem idênticos, ocorre o cascateamento por ordem física: a última regra escrita no código substitui as anteriores e toma a precedência.
  • Se os seletores forem diferentes, o navegador calcula o nível de especificidade baseado em três contadores: A (quantidade de IDs), B (quantidade de classes e atributos) e C (quantidade de tags de tipo). Seletores com maior pontuação anulam os mais genéricos. Estilos declarados diretamente no atributo inline superam as folhas de estilo externas ou internas.

Herança: Elementos filhos inseridos dentro de outros elementos herdam de forma automática as propriedades de texto e cores de seus ancestrais (como as propriedades color e font-family). Propriedades de estrutura física, como a propriedade de borda (border), não são herdadas automaticamente.

5. Aplicando Cores no CSS

O CSS gerencia cores tanto para o primeiro plano (propriedade color) quanto para o fundo de caixas e seções (propriedade background-color). Os formatos aceitos de inserção são:

  • Nomes de Cores: Palavras-chave textuais literais para mais de 140 cores predefinidas no padrão (como darkblue ou hotpink).
  • Valores Hexadecimais: Códigos alfanuméricos de 6 dígitos precedidos pelo caractere #, representando os canais Vermelho, Verde e Azul (ex: #FFFF00 para amarelo).
  • Valores RGB: Notação baseada na intensidade de vermelho, verde e azul informada por inteiros na escala de 0 a 255.
  • Valores RGBA: Uma extensão do RGB que introduz um quarto parâmetro correspondente ao canal alfa, que varia de 0.0 (transparência total) a 1.0 (opacidade completa).
  • HSL e HSLA: Sistema baseado nos parâmetros de Matiz (Hue, um ângulo de 0° a 360°), Saturação (porcentagem) e Luminosidade (porcentagem). A variação HSLA também engloba o controle de opacidade alfa.

6. Formatação de Texto e Tipografia

O controle tipográfico e estético do texto é feito através de um grupo de propriedades dedicadas:

  • font-family: Determina a fonte do texto. É obrigatório indicar opções de reserva (fallbacks) separadas por vírgula, finalizando a declaração com famílias genéricas como serif, sans-serif ou monospace. Nomes de fontes que contêm espaços vazios devem ser escritos entre aspas.
  • font-size: Ajusta a escala e tamanho do texto, recebendo unidades absolutas em pixels (px) ou unidades relativas como porcentagens e a unidade em (baseada na largura da letra "m").
  • font-style e font-weight: Configuram, respectivamente, a inclinação visual do texto (como o valor italic) e o peso da fonte em negrito (normal, bold, ou escalas numéricas que variam de 100 a 900).
  • Propriedades de Alinhamento e Efeito: Incluem o text-transform (conversão para uppercase, lowercase ou capitalize), text-decoration (aplicação de estilos como underline, line-through ou overline), text-align (alinhamento em left, right, center ou justify), além de controles para espaçamento como line-height (altura da linha), letter-spacing, word-spacing, vertical-align e text-shadow (sombra projetada no texto).

7. Projetando e Customizando Listas

Listas estruturadas recebem parametrização visual por meio de propriedades que alteram seus marcadores originais:

  • list-style-type: Altera os símbolos de marcação. Em listas não ordenadas (ul), aceita parâmetros como none, disc, circle e square. Em listas ordenadas (ol), aceita formatos como decimal, decimal-leading-zero, lower-alpha, upper-alpha, lower-roman e upper-roman.
  • list-style-image: Permite substituir os marcadores padrão por um arquivo gráfico customizado passando o caminho através de uma URL.
  • list-style-position: Ajusta o recuo e alinhamento do marcador em relação ao texto da lista, utilizando os valores outside (marcador fora do bloco de texto) ou inside (marcador embutido no fluxo da primeira linha).

8. Projetando e Organizando Tabelas

Para customizar e organizar os dados em tabelas do HTML, o CSS disponibiliza propriedades estruturais específicas:

  • border: Uma propriedade compacta (shorthand) que permite unificar a largura (border-width), o estilo (border-style, como solid ou dashed) e a cor da borda (border-color) em uma única linha de código.
  • border-collapse: Utiliza a configuração collapse para forçar que as células vizinhas compartilhem a mesma linha divisória, removendo as bordas duplas nativas do HTML.
  • padding: Determina o espaçamento interno, afastando o conteúdo textual das linhas de borda da célula da tabela.
  • Uso de Pseudo-classes: O texto destaca o uso de seletores dinâmicos como :first-child para alvejar elementos iniciais (como a primeira coluna) e :nth-child() recebendo parâmetros matemáticos ou termos como odd (linhas ímpares) e even (linhas pares) para gerar o efeito visual de linhas alternadas.

9. Princípios Básicos de Posicionamento

O CSS interage com a árvore estrutural reconhecendo a divisão dos elementos entre Block-Level (elementos de bloco que iniciam em uma nova linha e se organizam verticalmente) e Inline-Level (elementos de linha que acompanham o fluxo horizontal do texto). A propriedade display altera esses estados usando os comandos block ou inline.

A ordenação das caixas na página é controlada e modificada pela propriedade position, que oferece cinco comportamentos principais:

  • static: É o modo padrão do navegador; os elementos seguem a ordem natural do fluxo do HTML.
  • relative: Permite deslocar o elemento em relação à posição original que ele ocuparia normalmente no fluxo da página através de eixos (top, left, etc.).
  • absolute: Tira o elemento do fluxo convencional da página, fixando sua posição em relação ao seu elemento pai mais próximo que possua posicionamento modificado.
  • fixed: Remove o elemento do fluxo e fixa-o em coordenadas rígidas tendo como referência direta a janela do navegador (viewport). O item não se desloca durante a rolagem.
  • sticky: Funciona de modo híbrido; o elemento se comporta como relativo até que a rolagem atinja um limite configurado na tela, fixando-se a partir daquele ponto.

10. Sistemas de Layout (Float, Flexbox e Grid)

A estruturação de páginas evoluiu através de diferentes mecanismos de diagramação detalhados no capítulo:

  • Float Layout: Desloca elementos para as margens esquerda ou direita através da propriedade float, permitindo que textos fluam ao redor deles. Em estruturas como formulários inline, necessita da inserção da propriedade overflow: hidden no elemento contêiner pai para forçar o ajuste de sua altura física e evitar o colapso do layout.
  • Flexbox Layout (Unidimensional): Sistema voltado para o alinhamento e distribuição flexível de subelementos em apenas uma dimensão (seja uma linha horizontal ou uma coluna vertical). É ativado declarando display: flex no elemento pai (flex container). Utiliza as propriedades justify-content (com valores como flex-start, flex-end, center, space-between, space-around, space-evenly) e align-items para gerenciar o alinhamento nos eixos, além de propriedades como flex-grow ou o atalho flex para gerenciar a elasticidade e crescimento dos itens filhos.
  • Grid Layout (Bidimensional): O modelo mais robusto, capaz de organizar elementos em uma malha ortogonal estruturada em linhas e colunas simultaneamente. É inicializado aplicando display: grid no elemento pai. As linhas e colunas são criadas com as diretivas grid-template-rows e grid-template-columns. Suporta o uso da unidade de fração fr para divisão proporcional do espaço (ex: 1fr 2fr) e permite que elementos filhos preencham espaços específicos na malha por meio da propriedade grid-column (ex: 1 / 2).

11. Ferramentas de Desenvolvedor e Design Responsivo

A depuração de conflitos gerados por herança, especificidade e a análise das dimensões físicas das caixas (Box Model: margens, bordas, preenchimentos e conteúdo) é feita através das ferramentas de desenvolvedor do navegador, como o Chrome DevTools. Na seção Elements, a aba Styles lista as regras de estilo ativas e desabilitadas, enquanto a aba Computed consolida os valores finais calculados para o elemento.

O conceito de Responsive Design (Design Responsivo) representa a capacidade de uma interface web reorganizar e adaptar seu layout a diferentes resoluções e tamanhos de telas (como monitores, tablets e smartphones). Essa técnica funciona com o uso de Media Queries, que são instruções capazes de ativar, modificar ou anular blocos de regras CSS baseando-se em condições físicas como a largura atual da tela do dispositivo.
